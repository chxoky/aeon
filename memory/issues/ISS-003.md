# chain-runner `consume:` has never worked for any chain

## Symptom

`morning-pipeline` step 2 declares `consume: [token-movers, market-context-refresh]`,
but `morning-brief` has never received that context — including on the first fully
green chain run (29885837291, 2026-07-21). Chains functioned as a sequencer only:
ordering and fan-out real, data hand-off inert. Chains reported success anyway,
because a missing context file was never treated as an error.

## Root cause

`.github/workflows/chain-runner.yml` (parse loop, ~line 216/220 pre-fix): the step
parser matched `consume:`/`var:` only when they appeared on the same `$line` that
matched `skill:`. In `aeon.yml`:

```yaml
      - skill: morning-brief
        consume: [token-movers, market-context-refresh]
```

`consume:` is on the next line, so the regex never fired → `STEP_CONSUME` unset →
`CONSUME` empty → `build_context` skipped entirely. `var:` had the identical latent
bug. The parser's documented single-line form `- skill: name, consume: [a, b]` is
not valid YAML (parses as one scalar string), so the only writable form was the
multi-line one the parser could not read.

## Evidence

- No `chore(chain): context for morning-brief` commit on any ref
- `.outputs/.chain-context-morning-brief.md` 404 on main; no history for `.chain-context-*`
- Green-run log jumps from "Pulled latest outputs" straight to "Dispatching: morning-brief"

## Fix

Parser now treats `- parallel:`/`- skill:` lines as step starts and attaches
`consume:`/`var:` from continuation lines to the current step; parsed steps are
echoed (with consume/var) at parse time; a `::warning::` fires when a declared
`consume:` yields an empty context file or one with `_Output not available._`
entries — the silence is what let this hide.

## Verification (2026-07-21, run 29887463021 on main post-merge)

- Parse echo: `Step 2: single [morning-brief] consume=[token-movers,market-context-refresh]`
- `chore(chain): context for morning-brief` commit `b4ac9d7ed` — 61-line
  `.outputs/.chain-context-morning-brief.md` (first ever)
- morning-brief consumed it and succeeded; chain conclusion: success; no warnings fired.
