### worker bug fix — sendTelegram silent drop (2026-06-16)
- symptom: freeform replies never arrived in Telegram; bot showed "⏳ On it..." with no follow-up
- root cause: `sendTelegram` used try/catch expecting `fetch` to throw on failure — but `fetch` only throws on network errors, not HTTP 4xx. Telegram's 400 "can't parse entities" (malformed Markdown in Claude's reply) was swallowed silently
- fix: replaced try/catch with `resp.ok` check; retries without `parse_mode: 'Markdown'` on any non-2xx
- also fixed: `AbortController` signal now passed to memory fetches in `_answerFreeform` so a slow GitHub response can't hold `Promise.allSettled` past CF's 30s wall-clock limit
- worker version: c9f8835d (deployed 2026-06-16)

### worker bug fix — X username extraction (2026-06-16)
- symptom: no x-trader-monitor AEON runs since 2026-06-08; twitterapi.io webhook firing but alerts silent
- root cause: `handleTwitter` resolved username via `tweet.screen_name ?? tweet?.author?.username` — neither field exists in twitterapi.io payloads; actual field is `tweet.user.screen_name`.
